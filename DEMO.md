# Founder demo runbook

The core story takes about one minute.

1. Start on **Decide** with Wajeeh Alam’s seeded profile.
2. Select **Build another full-stack productivity SaaS** and analyze it.
3. Point out the low marginal profile value and the three overlapping projects.
4. Compare that with **Contribute to ML infrastructure used by real developers**.
5. Open **Compare** to show how leverage, new evidence, and time trade off.
6. Open **Profile**, switch to the beginner test profile, and evaluate the SaaS idea again.

The last step is the product thesis: the activity did not change; the student context did. Its marginal value should rise substantially for a student who has never shipped software.

Before a live demo, run:

```bash
npm run check
```

Keep mock mode enabled so the demo has no external dependency.
